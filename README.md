# 공홈 번역 덮어보기 · v0.1.9

원하는 서비스에서 직접 번역하고, 번역 결과나 직접 작성한 한국어를 실리태번의 말풍선에 붙여넣는 확장입니다.

## 설치

1. ZIP을 풉니다.
2. 압축에서 나온 `Manual-Web-Translation` 폴더를 실리태번 설치 폴더의 `data/default-user/extensions/` 아래에 넣습니다. 다른 실리태번 사용자 계정을 쓰면 `default-user` 대신 해당 계정 폴더를 사용하세요. 모든 실리태번 계정에 설치하려면 `public/scripts/extensions/third-party/`에 넣을 수도 있습니다.
3. 브라우저에서 실리태번을 새로고침합니다. 확장 관리 목록에서 **공홈 번역 덮어보기**를 확인합니다.

기본 사용자 설치 시 `SillyTavern/data/default-user/extensions/Manual-Web-Translation/manifest.json`이 보이면 폴더 위치가 맞습니다.

## AI 답변을 한국어로 보기

1. 답변 말풍선의 이름 바로 옆 **한국어 표시문 편집** 아이콘을 누릅니다.
2. **번역 프롬프트**를 원하는 문구로 바꿀 수 있습니다. **한영 병기**를 켜면 서술은 한국어로 쓰고, 대사 뒤에만 영어 원문을 괄호로 붙이라는 지시가 추가됩니다. 예를 들어 노라는 목도리를 단단히 여몄다. “막차는 아홉 시에 출발해.(The last bus leaves at nine.)”
3. **번역 요청 복사**를 누르고 원하는 서비스에 붙여넣어 전송합니다. 고유명사 표기를 지정하려면 **고유명사 같이 복사**를 사용합니다.
4. 번역 답변을 복사해 실리태번의 **화면에 표시할 번역문**에 붙여넣고 **적용**합니다.
5. 말풍선 아래 **원문 보기 / 한국어 보기**로 두 텍스트를 오갑니다.

편집창 오른쪽 위의 ChatGPT, Gemini, Claude 아이콘은 해당 공식 채팅 페이지를 새 탭에 엽니다.

## 내 메시지도 한국어로 보기

한국어로 작성한 글을 원하는 서비스에서 영어로 번역해 실리태번에 영어로 보냅니다. 보낸 말풍선에서 **한국어 표시문 편집**을 열고 처음에 쓴 한국어를 붙여넣습니다. 이미 영어로 작성한 메시지도 AI 답변과 같은 순서로 한국어를 붙일 수 있습니다.

## 복사 버튼과 고유명사 사전

| 버튼 | 복사 내용 |
| --- | --- |
| 프롬프트 복사 | 번역 프롬프트와 켜 둔 옵션 |
| 번역 요청 복사 | 번역 프롬프트와 켜 둔 옵션 → 영어 원문 |
| 고유명사 같이 복사 | 번역 프롬프트와 켜 둔 옵션 → 고유명사 사전 → 영어 원문 |
| 원문 복사 | 영어 원문 |

**고유명사 사전**에 `챗시 = chatsi`처럼 한 줄에 하나씩 입력합니다. 사전은 **고유명사 같이 복사**로 복사할 때만 포함됩니다. 프롬프트, 한영 병기 선택, 사전은 실리태번 설정에 자동 저장됩니다.

번역 프롬프트를 복사하면 태그와 속성은 유지하고 태그 사이의 텍스트는 번역하라는 지시가 붙습니다. 이미 저장한 프롬프트에도 적용됩니다. **원문 복사**는 원문만 복사합니다.

**적용**을 누르면 원문과 일치하는 태그에 추가된 마크다운 백슬래시를 제거합니다. 태그 구조가 원문과 일치하면 태그 안에서 백슬래시로 바뀐 줄바꿈도 실제 줄바꿈으로 복원합니다. 이미 저장한 번역문도 편집창에서 다시 **적용**해 고칠 수 있습니다.

## 저장과 표시

- 영어 본문은 기존 `mes`, 화면에 표시할 한국어는 `extra.display_text`를 사용합니다.
- 원문 보기는 화면만 전환합니다. 편집창에서 **번역문 삭제**를 누르면 선택한 말풍선의 번역문을 챗 파일에서 지우고 원문을 표시합니다.
- 매직 번역 등 같은 표시 필드를 사용하는 확장의 자동 번역이 켜져 있으면 새 번역 결과가 해당 표시문에 적용될 수 있습니다.
